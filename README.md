# MobTime

# Description
This app trackes app usage with consult of inactivity and uninstalled apps. It uses Digital Wellbeing app data made by Google and extends it with new functionality. It's done for Engineering Work in studies.

# AI Usage Warning
Google Gemini 3.5 Flash is used to prototyping app and functionality (in prototype-llm prefix branches). Any of genereted code isn't used in final version app.

# Used tools
- Google Gemini 3.5 Flash 
- Jetpack Compose 
- Kotlin 
- SQLite 
- Android API
